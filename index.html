AI News Navigator

huggingface.co

Keeping up with AI research, made easier. The app collects fresh papers and posts from arXiv, Hugging Face Daily Papers and leading AI lab blogs. Ask a question and a LangGraph agent plans searches, runs hybrid retrieval (BM25 + FAISS), reranks and grades the candidates, then writes a short cited answer with a "read these first" list. It runs entirely on open-weight models and also works as an MCP server for other agents.

Built with LangGraph (retrieve, rerank, grade, generate), query-rewrite prompts with arXiv fallback, hybrid search (BM25 + FAISS), bge reranking, open-weight models and Gradio.

MCP Forecast-Drift Alert Tool

internal · InterProductTec

Forecasts quietly degrade when menus, prices or footfall change. This MCP server watches live forecast accuracy (MAPE/WAPE and bias) across 300+ locations and raises an alert when system accuracy drifts past its limit, before customers notice. Because it speaks MCP, LLM agents can also call it as a tool to check forecast health and explain what changed.

Built with MCP, Python, MLflow and Sentry.

Internal tool, no public demo

Newsvendor Problem Visualiser

streamlit.app

A graphical way to understand the newsvendor problem — the trade-off behind every daily order. Simulate demand, set stockout and overstock costs, choose a safety margin and watch the losses change; consecutive stockout days cost more, like real customer frustration. Then let the app search for the loss-minimising margin.

Built with Python and Streamlit.
